A small project to play around with database sharding, read replicas, and other distributed systems concepts.

Primarily using docker and postgresql. Uses the schema from my other hobby project -- [expenses](https://github.com/k-amin07/expenses) -- a personal expense manager backend written in golang. Hopefully this can become a plug and play solution that can be used directly with that project, but may also diverge since the primary goal here is to ensure everything works from an infrastructure standpoint.

[plan.md](plan.md) in the root of the project is an execution plan devised with the help of gemini. Basically there to ensure I have an end goal in sight so I dont eventually end up abandoning the project.
